public static int assess(int attempts, int score, boolean verified) { if (attempts < 0 || score < 0) { // N1, N2 return -1; // N3 } int risk = 0; // N4 int i = 0; // N5 while (i < attempts && i < 3) { // N6, N7 if (score < 50) { // N8 risk += 2; // N9 } else { risk -= 1; // N10 } i++; // N11 } if (verified && risk <= 1) { // N12, N13 return 1; // N14 } if (risk >= 4 || score < 40) { // N15, N16 return 0; // N17 } return 2; // N18 }

The CFG models Java short-circuit evaluation by representing each atomic Boolean expression as a separate node.
